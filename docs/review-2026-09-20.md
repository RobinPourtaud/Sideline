# Review — 2026-09-20

Reviewed the collectors, playback/session lifecycle, preferences, rendering, controls, translation, extension manifests, CI, and test harness. This is a code and fixture review, not a store approval or a guarantee against changes to YouTube.

## Assessment

| Dimension | Assessment | Evidence and limits |
| --- | --- | --- |
| Security / privacy | Low observed risk | No runtime dependencies, backend, account mutations, copied HTML, or remote executable code. Media URLs are restricted; text uses DOM text nodes. Dependency audit reports no known vulnerabilities. This is not an independent security audit. |
| Correctness | Medium residual risk | Reproduced lifecycle, comment identity, rendering, and translation bugs are fixed. YouTube DOM changes and real native translation remain external uncertainties. |
| Performance | Bounded, needs live endurance testing | Rows, lanes, pending translations, and caches have caps. The 1,000-message fixture checks render churn. Comment collection still rescans up to 1,000 loaded threads after relevant mutations; sustained CPU/memory on busy streams has not been measured in this review. |
| Maintainability | Good separation, moderate UI complexity | Collection, core state, playback, browser integration, and rendering are separate with no framework. Panel still coordinates preferences, focus, and translation controls; a later extraction of translation settings could simplify it without changing behavior. |

## Findings addressed

- **Medium — old-video chat after SPA navigation.** The new session could consume an iframe still containing the previous video's chat. [chat.ts:59](../src/youtube/chat.ts#L59) now checks both the iframe URL and its loaded document against the current video ID. The regression constructs this navigation race explicitly. Documents without a video identifier cannot be conclusively attributed from their URL.
- **Medium — stale timestamp comments after edits.** When a comment had no permalink, its text hash changed on edit, leaving the old cached reference behind. [comments.ts:45](../src/youtube/comments.ts#L45) retains identity for an existing DOM thread. References update in place, including when their time changes, a permalink arrives later, or the loaded thread loses its content. Pending scans are cancelled when the comment root changes.
- **Medium — floating text did not update.** [floating-comments.ts:69](../src/ui/floating-comments.ts#L69) ignored changed content for an existing ID. This also meant asynchronous translations could remain invisible. Active nodes now refresh their contents and scrolling keyframes without resetting animation time.
- **Medium — overlapping fixed danmaku.** Lane spacing omitted the fixed message padding. It now includes padding and a gap, with a browser regression at the smallest text size.
- **Medium — translation restart could stay blocked.** A cancelled native request that did not settle left the shared running flag set. [Translation work](../src/translation/native.ts#L103) is now scoped to its abort signal, allowing a new session to proceed without a stale completion unlocking its queue. A disposed session cannot create another translator.
- **Low — timestamp URL validation was incomplete.** [Timestamp parsing](../src/core/timestamps.ts#L13) now rejects non-HTTPS URLs, credentials, and nonstandard ports in addition to checking the host and video ID.
- **Test infrastructure — Firefox smoke used the old launcher location.** Its selector now enters the launcher's own shadow root. The installed add-on smoke remains distinct from fixture-only Firefox tests.
- **Test reliability — asynchronous layout.** Customization geometry is sampled in matching hover states relative to the player in one browser evaluation, avoiding page scrolling between measurements. The fixture video is now a block element: its inline baseline gap had created five pixels of scrollable overflow that Chromium scrolled during automated clicks. Production focus transfers also prevent incidental scrolling. The danmaku translation check waits for its animation to attach before setting its baseline time.

## Remaining limitations and follow-ups

1. **Native translation needs a successful real-browser run.** Mocked tests validate lifecycle, errors, and rendering, not language-pack delivery or translation quality. A native translation call can stall; switching translation off and on now recovers the queue. There is a setup timeout but no per-message timeout.
2. **DOM collection is inherently partial.** Only loaded chat and up to 1,000 regular comment threads are collected. Replies are excluded. Cached regular comments survive DOM unloading; unloading cannot reliably be distinguished from server-side deletion. Identical author/text comments without a stable permalink may share a fallback ID. Test changing YouTube layouts and live moderation manually.
3. **Browser coverage is narrower than declared minimum versions.** Current Linux Chromium, Firefox, and WebKit fixtures are tested. WebKit coverage is not Safari extension packaging. Native macOS Firefox, minimum supported browser versions, Windows, and assistive technologies still need manual runs.
4. **Long-session performance remains unmeasured.** Run a busy live stream and a long replay with repeated seeks, theater/fullscreen changes, ads, and navigation. Measure CPU and retained memory, especially when many regular comments are loaded.
5. **Live-site checks were not repeated during this review.** Existing documentation records earlier successful YouTube smoke checks. This review does not extend those observations to the latest source changes or to every YouTube layout.

No new dependencies or permissions were added. See [testing.md](testing.md) for execution results and earlier manual checks.
