# Sideline v0.2.0

**YouTube comments, on screen.** This release adds smarter repeat handling and smoother scrolling, and opens Sideline to contributors.

![Sideline scrolling comments](https://raw.githubusercontent.com/RobinPourtaud/sideline/v0.2.0/docs/assets/v0.2.0/01-scrolling.png)

## What’s new

- **Quiet, Balanced, or Lively.** Quiet remembers repeated chat for 60 seconds; Balanced groups five-second bursts; Lively keeps individual messages. Forty matching greetings become one **Hello +39**.
- **Matching without the noise.** Case, punctuation, and symbols are ignored while symbol-only reactions, custom media, and paid messages retain their identity.
- **Smooth count updates.** Counters change in place, with reserved width and no animation restart. Resizing keeps comments at their current positions and updates spacing for the new player width.
- **Likes on timed reactions.** Available like counts appear alongside loaded timestamped comments.
- **A more welcoming project.** New README, user and contribution guides, issue templates, and a refreshed set of real-interface screenshots and promotional assets.

About half of Sideline was vibe-coded with AI assistance. The source is open for inspection and improvement, and all contributions are welcome: bugs, translations, cleanup, design, and browser testing.

## Download and install

| File | Use |
| --- | --- |
| `sideline-0.2.0-chrome.zip` | Extract, then select **Load unpacked** in `chrome://extensions` with Developer mode enabled. |
| `sideline-0.2.0-firefox.zip` | Extract, then load `manifest.json` through `about:debugging#/runtime/this-firefox`. This unsigned development build is temporary and lasts until Firefox restarts. |
| `sideline-0.2.0-sources.zip` | Reviewer/build source with the lockfile and BUILDING.md; use Node.js 24+. |
| `SHA256SUMS.txt` | Checksums for the three downloadable archives. |

Open or reload a YouTube watch page and click the Sideline player icon. Store publication follows each store’s review process; a GitHub release does not imply store approval or a Mozilla signature.

## Privacy and scope

Comment processing remains local. No Sideline account, backend, analytics, or comment uploads. Repeat history is bounded and stays in memory. Sideline reads loaded comments; it does not scan every comment or include replies. See the [user guide](https://github.com/RobinPourtaud/sideline/blob/v0.2.0/docs/usage.md), [privacy policy](https://github.com/RobinPourtaud/sideline/blob/v0.2.0/PRIVACY.md), and [changelog](https://github.com/RobinPourtaud/sideline/blob/v0.2.0/CHANGELOG.md).

The release is checked with unit, fixture-browser, package, and secret scans. Tests and synthetic burst measurements do not guarantee smoothness on every live stream. The remaining node-forge development-tool advisory is documented in [SECURITY.md](https://github.com/RobinPourtaud/sideline/blob/v0.2.0/SECURITY.md); patched shell-quote and source-map-js versions are included in the lockfile.
