# v0.2.0 open-source release review

Reviewed on October 11, 2026.

- Gitleaks 8.30.1 scanned all seven existing Git commits and the candidate release tree with redacted reporting. No secrets were detected. Generated output, environment files, private keys, and unpublished design explorations are excluded from Git.
- Node 24 checks passed: TypeScript, Biome, and 64 unit tests. The full Chromium/WebKit fixture run passed 162 cases with two Chrome-only skips; seven targeted Chromium checks passed again after the tooling and icon changes. Firefox's local temporary-profile issue remains documented in testing.md; Linux CI supplies installed-package validation.
- Chrome and Firefox production packages use version 0.2.0. Firefox package lint reported zero errors and warnings. A fresh extraction of the reviewer source archive ran npm ci and both production builds; all 24 files in each output were byte-identical to the release builds.
- Production dependency audit reported zero vulnerabilities. Patched shell-quote and source-map-js versions are locked. The remaining node-forge development-tool advisory is assessed in SECURITY.md and is not represented as fixed.
- Comment rendering uses text nodes and DOM APIs, constrained media URLs, bounded repeat memory, and disposal hooks. No Sideline backend, credentials, comment uploads, analytics, or production string evaluation were added.
- Five 1280×800 feature screenshots, a 440×280 promotional tile, and a 1400×560 marquee passed raster inspection as opaque RGB images. Screenshots capture the actual interface with synthetic comments; the original scene, editable layouts, and font license are included separately from extension packages.
- The README, contribution guide, store copy, and release notes explicitly disclose that about half the project was vibe-coded and welcome contributions. The original mark is preserved.

Secret scanning and fixture performance measurements have practical limits. See SECURITY.md and docs/testing.md for the upstream advisory, browser profile issue, and live-site validation scope. Store review and Mozilla signing are separate from the GitHub release.
